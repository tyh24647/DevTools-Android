# Android release setup

- Open this project in Android Studio. Compile/target SDK 36, min SDK 26, compatible Android Studio bundled JDK (Java compilation target 17), AGP 9.4.1, Gradle 9.6.0, Kotlin/Compose compiler 2.2.10.
- The release package is com.tyh24647.devtools. Register it in Play Console, configure app signing and generate a signed AAB using Android Studio's Build → Generate Signed App Bundle / APK flow. Release source defaults have no Pro preview entitlement. The delivered APK is for debug testing, not store distribution.
- Create devtools_pro_monthly (monthly subscription base plan) at your intended $2.99 US price and devtools_pro_lifetime (one-time, non-consumable) at $19.99. Add your licensing public key as described in gradle.properties.example. Publish an internal testing build and configure license testers. Test successful, pending, cancelled, expired, revoked, already-owned and restored purchases.
- Local RSA verification is implemented, but a production verification server with Play Developer API checks and real-time developer notifications should enforce current entitlement state and resist token replay. Acknowledgement, refresh and restore need real Play-track testing.
- Ads default to disabled to match the current upstream feature flag. When enabling, configure your AdMob application/ad-unit IDs and UMP privacy messages. Test no-fill, consent denial, privacy-options changes, full-screen lifecycle and Pro suppression. Advertising ID permission is removed from the merged app manifest; requests use the non-personalized setting. Review actual SDK data collection for Data Safety disclosures.
- Supply a public privacy policy describing local browsing/rule storage, optional ad processing, Google Play purchases and npm/jsDelivr update checks. No browsing URLs, rules or logs are sent by app code to ad or package services. SDK device/network processing still needs disclosure.
- Test injection and navigation on Android 8.0 and current Android versions with different System WebView providers. Validate file upload flows, back behavior, SPA route changes, CSP-restricted sites, HTTP local development and six share targets. Browser pages do not share cookies with Chrome.
- Review interpreted-JavaScript update behavior against current Google Play policy before submission. Only catalogue-mapped JS files are downloaded; there is no APK, DEX, JAR or native-library self-update path, and inspected pages have no native JavascriptInterface. Metadata hashes detect corruption and service inconsistency, not an independently signed release.
- Review upstream package licenses when updating. Notices for the npm packages are included; AndroidX and Kotlin dependencies follow their upstream licenses and Google SDKs their published terms.
- A Firefox Android extension remains a separate follow-up distribution. Chrome for Android cannot host this app as an extension.
